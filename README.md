# 🎮 Quiz Game

## 📌 Description
Quiz Game is a console-based application developed using Python. It allows users to test their knowledge by answering multiple-choice questions with different difficulty levels. The game includes a timer system, scoring mechanism, and a leaderboard to track top scores.

## 🚀 Features
- 🟢 Multiple difficulty levels (Easy, Medium, Hard)
- ⏱️ Timer-based questions
- 🎯 Score calculation with bonus points for quick answers
- 📊 Leaderboard system using JSON file
- 🔀 Randomized questions for better gameplay

## 🛠️ Technologies Used
- Python
- Libraries: `random`, `time`, `json`, `os`
